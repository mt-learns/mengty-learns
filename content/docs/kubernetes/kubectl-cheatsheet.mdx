# Kubectl Cheatsheet

Quick reference for Kubernetes operations.

<Tip>
  Use `kubectl explain <resource>` to get built-in documentation for any resource field.
</Tip>

## Get Resources

```bash
kubectl get pods
kubectl get nodes
kubectl get services
```

## Logs and Debugging

```bash
kubectl logs <pod-name>
kubectl exec -it <pod-name> -- /bin/bash
```
