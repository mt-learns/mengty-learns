# GitHub Actions Workflow

Automate your build, test, and deployment pipeline.

<Gotcha>
  Pin action versions to a full SHA or trusted major tag to avoid unexpected breaking changes.
</Gotcha>

## Example Workflow

```yaml
name: CI
on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install
      - run: npm test
```
