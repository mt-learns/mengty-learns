## TL;DR
A **performance budget** pairs a concrete metric (**API p95**, **queries per request**, **JS bundle KB**, or **Core Web Vitals**) with a hard **CI threshold**. Without an automated gate, performance erodes by 200ms per sprint until users abandon the app.

## Why it exists
No single PR ruins performance. One PR adds a chart library, the next adds an unindexed query, and a third adds a full icon barrel import. Eighteen months later, page load has tripled and no single commit is to blame.

## Mental model
Measure **before** optimizing, gate **every PR** in CI, and calibrate budgets with **real-user monitoring (RUM)**.

## Do it

### Four high-leverage budgets

| Budget | Example threshold | What it catches |
|---|---|---|
| **Queries per request** | `<= 5–10` per endpoint | N+1 ORM lazy-loading loops |
| **API p95 latency** | `< 300–400ms` | Missing indexes, chatty downstream RPCs |
| **Route JS bundle** | `< 200–250 KB` gzip | Accidental barrel imports (`import *`), unsplit heavy widgets |
| **Core Web Vitals** | `LCP < 2.5s`, `INP < 200ms`, `CLS < 0.1` | Render-blocking assets, layout shifts, main-thread TBT |

### Real example in this site
This repository enforces Lighthouse CI budgets in `.github/workflows/quality.yml` and lazy-loads heavy client libraries (such as `@xyflow/react`) only on pages that render a `<Flow>` and only when scrolled into view (`IntersectionObserver`), keeping non-flow pages at 0 KB of React Flow JS.

```ts
// Good: dynamic import keeps heavy widgets out of the initial route bundle
const LazyFlow = dynamic(() => import('@/components/flow/Flow'), {
  ssr: false,
  loading: () => <FlowSkeleton />,
});
```

## Gotchas
- **Warning-only budgets:** A CI warning that never fails the build gets ignored within two sprints.
- **Unthrottled lab tests:** Testing on an M-series laptop over fiber hides 4-second INP/LCP on mid-tier Android or corporate VPNs.
- **Premature micro-optimization:** Tuning a helper that takes 0.5% of request time while an N+1 loop takes 80% wastes effort—always profile first.

## Production checklist
- [ ] Assert constant query counts in repository integration tests for list endpoints.
- [ ] Enforce Core Web Vitals (`LCP`, `INP`, `CLS`) and bundle budgets in CI (e.g. Lighthouse CI).
- [ ] Lazy-load heavy charts, editors, and diagram canvases outside the critical initial bundle.
- [ ] Segment production latency (p75/p95) by route and tenant so outliers are visible.
