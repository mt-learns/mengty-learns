### TL;DR
A quick reference for everyday Git workflows: creating branches with `switch`, staging partial changes, keeping history clean with `rebase`, and safely undoing mistakes with `restore` or `revert`.

## Status and staging

```bash
git status --short               # compact working-tree and index status
git diff                         # unstaged changes
git diff --staged                # staged changes ready for the next commit
git add -p                       # interactively stage hunks
git restore <file>               # discard unstaged edits in a tracked file
git restore --staged <file>      # unstage without losing working-tree edits
```

## Branches and worktrees

```bash
git switch -c feat/login         # create and switch to a new branch
git switch main                  # switch back to main
git branch -d feat/login         # delete a merged branch (-D to force)
git worktree add ../wt-hotfix main  # check out another branch in a separate directory
git worktree remove ../wt-hotfix    # remove the extra worktree when done
```

<Tip>
  Prefer `git switch` and `git restore` over `git checkout` — they separate branch switching from file restoration and prevent accidental detached-HEAD edits.
</Tip>

## Commits, rebase, and history

```bash
git commit -m "feat: add login"
git commit --amend --no-edit     # fold staged changes into the last commit
git log --oneline --graph -n 15  # compact branch graph of recent commits
git fetch origin
git rebase origin/main           # replay local commits on top of updated main
git push --force-with-lease      # safe force-push after rebasing a private branch
```

<Gotcha>
  Never rebase or `reset --hard` commits that others have already pulled onto a shared branch. Use `git revert <sha>` to record an undo commit instead.
</Gotcha>

## Undoing and recovering

| Goal | Command | Rewrites history? |
|---|---|---|
| Undo last commit, keep changes staged | `git reset --soft HEAD~1` | Yes (local) |
| Undo last commit, keep changes unstaged | `git reset HEAD~1` | Yes (local) |
| Undo a pushed commit safely | `git revert <sha>` | No |
| Temporarily shelve uncommitted work | `git stash push -u -m "wip"` | No |
| Find a lost commit after a bad reset | `git reflog` | No |
