## TL;DR
Animation exists to guide attention and explain spatial orientation. Keep durations fast (200–300ms), animate only `transform` and `opacity`, and always disable motion when `prefers-reduced-motion` is active.

## Why it exists
Unconstrained UI animation creates cognitive load and motion sickness. Bouncing icons, 800ms fade-ins on static text, and layout-shifting height expansions make an app feel sluggish and unprofessional. Motion with purpose acts as a visual cue that maintains user orientation during page transitions and state changes.

## Mental model
**Physics over keyframes.** Natural motion accelerates and decelerates smoothly (spring or ease-out). 

| Parameter | Recommended range | Why |
|---|---|---|
| **Duration** | 200ms – 350ms | Fast enough not to delay interaction; slow enough to track visually. |
| **Properties** | `transform`, `opacity` | Handled by GPU compositor thread; zero layout reflow. |
| **Easing** | Cubic bezier (`0.32, 0.72, 0, 1`) | iOS-style spring feel: quick start, gentle deceleration. |

## Do it
### Respecting Reduced Motion in React / CSS
```tsx
'use client'
import { motion, useReducedMotion } from 'motion/react'

export function FadeInCard({ children }: { children: React.ReactNode }) {
  const shouldReduceMotion = useReducedMotion()

  return (
    <motion.div
      initial={shouldReduceMotion ? { opacity: 1 } : { opacity: 0, y: 10 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{ duration: 0.25, ease: [0.32, 0.72, 0, 1] }}
    >
      {children}
    </motion.div>
  )
}
```

## Gotchas
- **Animating `width`, `height`, or `top`** forces browser layout recalculation (reflow) on every frame, causing jank. Use `transform: scale()` or `translate()` instead.
- **Ignoring `prefers-reduced-motion`** violates accessibility standards and can induce nausea in sensitive users.
- **Endless loaders or bouncing badges** distract attention away from core content.

## Production checklist
- [ ] Animations run on `transform` and `opacity` only (no layout reflow).
- [ ] Durations are kept under 300ms for UI micro-interactions.
- [ ] `prefers-reduced-motion` hook or CSS media query disables non-essential motion.
- [ ] Motion serves a clear pedagogical or spatial purpose (e.g. sheet open, tab switch).
