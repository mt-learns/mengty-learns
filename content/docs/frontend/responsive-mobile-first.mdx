## TL;DR
Start styling at 360px mobile width, then layer on larger screens (`md:`, `lg:`). Enforce 44px minimum tap targets, fluid typography, and container queries so components adapt to their container rather than the viewport.

## Why it exists
Designing desktop-first results in cramped mobile layouts, hidden sidebars, and tiny touch targets that frustrate mobile users. A mobile-first approach forces prioritization: what matters most fits on a 360px phone screen; larger screens gain breathing room and multi-column grids.

## Mental model
**Min-width stack.** Unprefixed classes apply everywhere. `md:` applies from 768px upwards.

| Breakpoint | Width | Typical device |
|---|---|---|
| Default | 360px+ | Mobile phone |
| `sm` | 640px | Large phone / small tablet |
| `md` | 768px | Tablet / iPad |
| `lg` | 1024px | Laptop |
| `xl` | 1280px+ | Desktop / 4K monitor |

## Do it
### Mobile-First Layout Pattern
```tsx
export function ResponsiveNav() {
  return (
    <nav className="flex flex-col space-y-2 p-4 md:flex-row md:items-center md:justify-between md:space-y-0">
      <span className="text-body font-semibold">Mengty Learns</span>
      <div className="flex flex-col space-y-2 md:flex-row md:space-x-4 md:space-y-0">
        <a href="/docs" className="min-h-tap flex items-center px-3 py-2">Docs</a>
        <a href="/review" className="min-h-tap flex items-center px-3 py-2">Review</a>
      </div>
    </nav>
  )
}
```

## Gotchas
- **Fixed width containers** (`w-[1200px]`) overflow on mobile devices; use `max-w-7xl w-full mx-auto px-4`.
- **Tiny tap targets** (`p-1` on an icon button) cause mis-taps on touchscreens; enforce `--tap-target: 44px`.
- **Viewport units (`100vh`)** on mobile browsers include the address bar, causing vertical scrolling bugs. Use `100dvh` (dynamic viewport height).

## Production checklist
- [ ] Layouts tested at 360px width without horizontal scrolling or clipping.
- [ ] Tap targets meet the 44px minimum requirement (`min-h-tap`).
- [ ] Tailwind breakpoints use min-width (`md:`, `lg:`), stacking up from mobile base styles.
- [ ] Text wraps cleanly and does not overflow narrow viewports.
