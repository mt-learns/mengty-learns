## TL;DR
HTTP security headers instruct browsers to lock down framing, MIME sniffing, downgrades to HTTP, referrer leaks, and script execution. In this repo (Next.js on **Cloudflare Workers** via OpenNext), `lib/security-headers.mjs` is the single source of truth for both `next.config.mjs` `headers()` (Worker-rendered routes) and `public/_headers` (Workers Static Assets).

## Header reference

| Header | Recommended baseline | Purpose |
|---|---|---|
| `Strict-Transport-Security` | `max-age=31536000; includeSubDomains` | Forces HTTPS in the browser after first visit. Add `; preload` only when every subdomain is permanently HTTPS. |
| `Content-Security-Policy` | `default-src 'self'; object-src 'none'; frame-ancestors 'none'; base-uri 'self'` | Restricts script/style/connect origins and blocks clickjacking (`frame-ancestors`). |
| `X-Content-Type-Options` | `nosniff` | Disables browser MIME-type sniffing. |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | Sends full path on same-origin, origin-only on cross-origin HTTPS, nothing on downgrade. |
| `Permissions-Policy` | `camera=(), microphone=(), geolocation=()` | Disables powerful browser APIs your site does not use. |
| `Cross-Origin-Opener-Policy` | `same-origin` | Isolates top-level browsing context from cross-origin popups (Spectre/XS-Leak mitigation). |
| `Cross-Origin-Embedder-Policy` | `require-corp` | Opts into cross-origin isolation (`SharedArrayBuffer`); only enable if all subresources send CORP/CORS. |

## Cloudflare Workers `_headers` & `next.config.mjs` (this repo)

> **Repo status:** In this repository, `lib/security-headers.mjs` defines the shared `securityHeaders` array used by `next.config.mjs` `headers()` (for HTML, RSC, and route handler responses built by the Worker) and mirrored in `public/_headers` (for static assets served from `.open-next/assets`, enforced by `lib/security-headers.test.ts`).

```text
# public/_headers (actual file in this repo, synced with lib/security-headers.mjs)
/_next/static/*
  Cache-Control: public, max-age=31536000, immutable

/*
  Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self' data:; connect-src 'self'; worker-src 'self' blob:; manifest-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'none'
  Strict-Transport-Security: max-age=31536000; includeSubDomains
  X-Content-Type-Options: nosniff
  Referrer-Policy: strict-origin-when-cross-origin
  Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=(), usb=()
  X-Frame-Options: DENY
```

## Gotchas
- **HSTS `preload` is hard to undo:** Submitting to the HSTS preload list bakes your domain into browser binaries. If a legacy internal subdomain still uses plain HTTP, `includeSubDomains` + `preload` will break it for months.
- **COEP breaks third-party embeds:** Adding `Cross-Origin-Embedder-Policy: require-corp` blocks third-party images/iframes that lack `Cross-Origin-Resource-Policy: cross-origin` or CORS headers.
- **`_headers` does not apply to Worker-rendered routes or `next dev`:** On Cloudflare Workers with Static Assets, `public/_headers` only applies to static asset responses—Worker-rendered HTML/RSC routes must also return headers from `next.config.mjs` `headers()`. Verify both with `curl -I`.

## Production checklist
- [ ] `X-Content-Type-Options: nosniff` and `Referrer-Policy` are set on all responses.
- [ ] Clickjacking is blocked with CSP `frame-ancestors 'none'` (or `'self'`).
- [ ] `Strict-Transport-Security` starts with a short `max-age` (e.g. `300`) before ramping to `31536000; includeSubDomains`.
- [ ] CSP is tested in `Report-Only` mode before enforcing so inline hydration/styles are not broken.
