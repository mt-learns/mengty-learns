## TL;DR
**Drift** happens when live cluster state diverges from Git—usually from a manual `kubectl edit`. A GitOps agent continuously compares live objects against Git, flags **OutOfSync**, and with **self-heal** enabled automatically **reconciles** the cluster back to Git.

## Intent
<Intent>
Understand how GitOps agents detect configuration drift and reconcile live clusters back to Git—and why manual hotfixes get overwritten unless they go through Git.
</Intent>

## Problem
During an outage, someone runs `kubectl edit deployment web` to bump replicas or change an environment variable, fixes the fire, and forgets to update Git. Weeks later, the next deployment silently wipes out that hotfix—or worse, nobody knows why production behaves differently from staging.

## Solution
GitOps treats reconciliation as a continuous control loop rather than a one-time deploy script:

1. **Observe:** The GitOps agent (Argo CD or Flux) watches live Kubernetes resources via the API Server and compares them against the rendered manifests from Git.
2. **Detect Drift:** Any difference in tracked fields (replicas, image tag, env vars) marks the application **OutOfSync**.
3. **Reconcile (Self-Heal):** With automated reconciliation enabled (`selfHeal: true` in Argo CD, or default periodic interval in Flux), the agent reapplies the Git manifests to `kube-apiserver`, overwriting the manual edit.
4. **Prune (optional):** If `prune: true` is set, resources deleted from Git are also deleted from the cluster.

## Real-world analogy
<Analogy>
Think of a hotel room inspector with a checklist photo (**Git**). If a guest moves the lamp and hangs a poster (**manual `kubectl edit`**), the inspector notices the room is **OutOfSync** and resets it to match the photo (**reconciliation**) before the next check-in.
</Analogy>

## Code
Comparing Flux (`Kustomization`) and Argo CD (`syncPolicy`) reconciliation settings:

```yaml
# Flux Kustomization reconciles drift automatically on its interval (not run)
apiVersion: kustomize.toolkit.fluxcd.io/v1
kind: Kustomization
metadata:
  name: web-app
  namespace: flux-system
spec:
  interval: 5m
  path: ./apps/web
  prune: true
  sourceRef:
    kind: GitRepository
    name: k8s-config
```

## How to implement
<Steps>
  <Step>
    ### Start with drift detection only
    Enable GitOps sync notifications so you see `OutOfSync` diffs before turning on `selfHeal`.
  </Step>
  <Step>
    ### Enable self-heal for stateless workloads
    Turn on `selfHeal: true` (Argo CD) or rely on Flux's reconciliation interval so drift heals automatically.
  </Step>
  <Step>
    ### Handle HPA and mutated fields cleanly
    Configure `ignoreDifferences` for fields mutated at runtime (such as `spec.replicas` when using a HorizontalPodAutoscaler).
  </Step>
</Steps>

## Pros / Cons
