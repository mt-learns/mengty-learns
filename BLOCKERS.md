# Typography (branch `typography`)

3. **Flow node labels now render in Inter, and two more clamp at 360px.** Before this branch Inter never applied: `app/global.css` had `:root { --font-inter: var(--font-inter); }`, a self-referencing custom property that invalidated the variable, so every page used the system font (Segoe UI on Windows). With Inter actually rendering, labels are wider. A scan of all 29 pages with flows at 360px (68 node labels) finds 4 labels hitting `line-clamp-2` against 2 before: `PlaceOrderPort` (already clamped) and `OrderRepoPort` on `/docs/architecture/hexagonal/`, `Push / PR Trigger` (already clamped) on `/docs/ci-cd/pipeline-anatomy/`, and `API Server + etcd` on `/docs/kubernetes/kubectl-apply/`. Node boxes, zoom and the fit ladder are unchanged, and `pnpm test` passes. Label tracking doesn't fix it (−0.01em: 4 clamped, −0.02em: 3), so the fix is in `components/flow` (node width at the narrow rung, or a 13px compact label), which is out of scope for the typography worker.
